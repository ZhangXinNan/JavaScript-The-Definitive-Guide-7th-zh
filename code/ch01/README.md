# 第1章 JavaScript简介
## 1.1 探索JavaScript
1. 少量代码，可以用浏览器的Web开发工具（F12,Ctrl+Shift+I），然后选择Console标签页。
2. 下载安装node，在命令行运行。

## 1.2 Hello World
hello.js
```js
console.log("Hello World");
```

1. 在命令行执行。
```bash
node hello.js
```
2. 在网页里hello.html加载js代码
```html
<script src="hello.js"></script>
```
